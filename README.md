# TradeDesk — локальная панель Discord-объявлений

Одна страница для публикации своего объявления через заданный интервал. Использует **пользовательский токен, не бот**. Не выполняет сделки, не нажимает команды игровых ботов и не обходит CAPTCHA или ограничения Discord.

**Важно:** self-bot автоматизация запрещена правилами Discord и может привести к блокировке аккаунта. Кулдаун не делает её разрешённой. Используйте только свой аккаунт и канал, где публикации разрешены. Не передавайте токен другим людям.

## Windows-приложение

Рекомендуемый вариант — один установщик `dist\TradeDeskSetup.exe`. Запустите его: файлы приложения распакуются в `%LOCALAPPDATA%\TradeDesk`, а на рабочем столе появится ярлык `TradeDesk`. Права администратора не нужны.

- При повторной установке файлы приложения обновляются, а профиль WebView2 с настройками сохраняется.
- Установщик содержит все файлы приложения и не требует отдельной папки рядом с собой.
- Требуется Windows 10/11 x64 и Microsoft Edge WebView2 Runtime. Если WebView2 не установлен, приложение покажет понятное сообщение и предложит открыть страницу загрузки.
- Отдельного деинсталлятора пока нет: закройте TradeDesk, удалите `%LOCALAPPDATA%\TradeDesk` и ярлык с рабочего стола.

Можно собрать и переносимую папку `dist\TradeDesk\`: запустите `TradeDesk.exe` — откроется отдельное окно TradeDesk, а не вкладка браузера. Папку нужно переносить целиком: рядом с exe должны оставаться каталоги `app\` и `runtime\`.

Сборка не подписана, поэтому при первом запуске Windows SmartScreen может предупредить. Если приложение получено из доверенного источника, нажмите «Подробнее» → «Выполнить в любом случае».

- Настройки карточек сохраняются в профиле WebView2: `%LOCALAPPDATA%\TradeDesk\WebView2`. Благодаря фиксированному локальному порту они переживают перезапуск приложения.
- Токены не сохраняются на диск. Поле токена остаётся заполненным до закрытия приложения или удаления карточки; после перезапуска токен нужно вставить снова.
- Приложение одноэкземплярное: повторный запуск активирует уже открытое окно. Закрытие окна останавливает встроенный локальный сервер.
- Один и тот же токен нельзя проверить или подключить в двух карточках. Сравнение идёт по точному значению после отбрасывания пробелов по краям; когда первый токен меняется или его карточка удаляется, заблокированная карточка проверяется автоматически.
- Интерфейс работает только с локальным сервером на `127.0.0.1:47831`, внешние окна, переходы и разрешения браузера заблокированы.

### Сборка приложения

Нужны Node.js 22+ (сборка запускается через `node.exe`) и .NET SDK 8+.

```cmd
node scripts/build-desktop.mjs
```

Скрипт публикует self-contained Windows-приложение в `dist\TradeDesk\`, добавляет `runtime\node.exe`, файлы сервера и `public\`. Готовую папку можно заархивировать и передать вместе с инструкцией из `dist\TradeDesk\README.txt`.

### Сборка установщика

После сборки папки приложения можно собрать один установщик:

```cmd
node scripts/build-bootstrapper.mjs
```

По умолчанию скрипт берёт `dist\TradeDesk\` и создаёт `dist\TradeDeskSetup.exe`. В установщик встраивается сжатый пакет приложения; при запуске он распаковывает файлы в `%LOCALAPPDATA%\TradeDesk` и создаёт ярлык на рабочем столе. Профиль `%LOCALAPPDATA%\TradeDesk\WebView2` не перезаписывается.

Для сборки установщика нужен только `csc.exe` из .NET Framework 4.8 (входит в Windows 10/11) и PowerShell; .NET SDK для этого шага не требуется. Для нестандартного расположения сборки можно задать переменные окружения `TRADEDESK_PAYLOAD` и `TRADEDESK_BOOTSTRAPPER_OUTPUT`:

```cmd
set TRADEDESK_PAYLOAD=D:\TradeDesk-build\TradeDesk
set TRADEDESK_BOOTSTRAPPER_OUTPUT=dist\TradeDeskSetup.exe
node scripts/build-bootstrapper.mjs
```

Установщик не подписан: SmartScreen может предупредить. Для автоматической установки без окна используйте `TradeDeskSetup.exe /silent`.

## Запуск из исходников

Для разработки можно запустить только веб-часть. Нужен Node.js 22 или новее; зависимости устанавливать не нужно.

```cmd
node server.mjs
```

Откройте точный адрес `http://127.0.0.1:...`, напечатанный в терминале. Порт выбирается автоматически. Для остановки сервера — Ctrl+C. Это режим разработки в браузере; пользователям предназначен `TradeDesk.exe`.

```cmd
node --test tests/*.test.mjs
```

Команды `npm start` и `npm test` работают так же, если PowerShell не блокирует `npm.ps1`.

## Использование

1. Нажмите «Добавить аккаунт» и вставьте пользовательский токен без `Bot `. Через 800 мс после ввода приложение проверит профиль через Discord (`GET /users/@me`), без публикаций. После успеха появятся остальные настройки, а заголовок, `@username` и аватар будут взяты из профиля. При изменении токена настройки снова скрываются. При отказе или отсутствии связи показывается ошибка. Токен проверяется повторно перед запуском.
2. Если такой же токен уже введён в другой карточке, вторая карточка показывает ошибку и не открывает настройки. Исправьте или удалите первую карточку — вторая проверится сама.
3. Укажите от 1 до 20 ID каналов (17–20 цифр), разделяя их новой строкой, пробелом или запятой, объявление до 2000 символов и кулдаун 60–86400 секунд. Повторяющиеся ID исключаются. Каналы обходятся по кругу: одна отправка за интервал, не одновременная публикация во все каналы.
4. Нажмите «Запустить отправку» в нужной карточке. Первая публикация происходит сразу, следующие — через интервал после ответа Discord. Демо и дополнительного подтверждения нет. До 20 карточек; один токен не может одновременно работать в нескольких карточках.
5. У каждого аккаунта независимые таймер, счётчик и журнал. «Остановить» действует на одну карточку; «Остановить все» — на сеансы текущего окна. Удаление карточки останавливает её сеанс и удаляет настройки. Уже принятый Discord запрос отменить нельзя. Токен остаётся в поле текущего окна, поэтому карточку можно запустить снова без повторного ввода; сервер удаляет свою копию токена при остановке.
6. Активные сеансы принадлежат запустившему их окну. Закрытие TradeDesk останавливает встроенный сервер сразу; в веб-режиме после перезагрузки вкладки дождитесь остановки по потере связи (15–17 секунд), затем можно запускать карточки заново.

## Данные и безопасность

- Токен существует только в памяти браузера/WebView2 и сервера. После запуска поле не очищается: токен остаётся в текущем окне до закрытия приложения, удаления карточки или замены токена. Остановка удаляет серверную ссылку на токен; перезапуск приложения или сервера тоже его теряет. Это не гарантированное обнуление всех копий строки в памяти ОС/JS.
- На диск токен не записывается; тела запросов, ответы Discord и секреты не логируются. Журнал в памяти ограничен 100 событиями.
- В localStorage сохраняются только ID карточек, списки ID каналов, объявления и интервалы. Старое поле одного канала автоматически переносится в список; прежние названия аккаунтов/серверов больше не сохраняются. Не помещайте секреты в текст объявления. В приложении настройки удаляются вместе с `%LOCALAPPDATA%\TradeDesk\WebView2` после закрытия TradeDesk; в браузере — очисткой данных сайта.
- Только loopback 127.0.0.1, проверка Host/Origin, отдельный ключ локального API, запрет cross-origin и встраивания. В приложении дополнительно запрещены внешние переходы, новые окна и запросы разрешений WebView2. Не выставляйте сервер в интернет и не проксируйте его наружу. Другие локальные программы с доступом к компьютеру не входят в эту модель защиты.
- Сервер напрямую обращается к `https://discord.com/api/v10`. Массовые упоминания отключены через allowed_mentions.
- Закрытие окна/вкладки или потеря связи с окном-владельцем останавливает сеанс после 15–17 секунд без heartbeat. До истечения этого срока возможна отправка. Для немедленной остановки используйте кнопку или закройте приложение. В веб-режиме фоновая заморозка вкладки также может остановить сеанс.
- 429: ожидание не меньше retry_after и заданного кулдауна. 400/401/403/404/5xx: остановка. При сетевой ошибке результат неизвестен, автоматического повтора нет, чтобы не дублировать публикацию. Проверьте канал вручную.
- Локальное приложение без пользователей, админки, платежей и внешней аналитики; заявки и контактные формы не отправляются.

## Дизайн и структура

UI/UX Pro Max установлен в `.claude/skills/ui-ux-pro-max`, revision `d14efff8ed1faa4187f004f79926f428c8074ec7`. Дизайн: тёмная панель в оттенках индиго и графита, стеклянные карточки аккаунтов с аватаром Discord, контрастные поля, заметные состояния входа и отправки, keyboard focus и reduced-motion. Применены рекомендации скилла по тёмным поверхностям, читаемости, доступным формам и адаптивной сетке. Дополнительно добавлен многослойный motion-слой: каскадное появление блоков и карточек, мягкий дрейф фона, подсветка и блик при наведении на карточку, анимация статусов, счётчиков и журнала, а также плавное удаление карточки. При `prefers-reduced-motion` анимации отключаются, задержки обнуляются, а декоративные слои скрываются. Системные шрифты используются вместо внешних запросов; аватар загружается браузером с публичного CDN Discord.

- `desktop/` — C# WinForms-хост, WebView2, тёмный заголовок окна и управление встроенным сервером.
- `installer/` — исходник самодостаточного установщика: распаковка в `%LOCALAPPDATA%\TradeDesk` и ярлык на рабочем столе.
- `scripts/build-desktop.mjs` — сборка папки `dist\TradeDesk\`.
- `scripts/build-bootstrapper.mjs` — упаковка папки приложения в один `TradeDeskSetup.exe`.
- `public/` — тёмный интерфейс, карточки аккаунтов, локальные настройки и журналы.
- `accounts.mjs` — независимые сеансы аккаунтов, владение окнами и общая остановка.
- `campaign.mjs` — валидация, отправка, кулдаун и жизненный цикл одного сеанса.
- `server.mjs` — локальный HTTP/API.
- `tests/` — тесты таймера и API; Discord в тестах подменён транспортом, реальные сообщения не отправляются.
- `scripts/install-skill.mjs` — загрузка скилла без запуска скачанного кода; повторный запуск сохраняет существующие файлы.

Реальная авторизация/публикация требует вашего аккаунта и разрешённого канала и не подтверждается тестами с подменённым транспортом. Никому не присылайте токен для проверки.
