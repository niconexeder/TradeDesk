# TradeDesk — локальная панель Discord-объявлений

Одна страница для публикации своего объявления через заданный интервал. Используется **пользовательский токен, не бот**. Приложение не выполняет сделки, не нажимает команды игровых ботов и не обходит CAPTCHA или ограничения Discord.

**Важно:** self-bot автоматизация запрещена правилами Discord и может привести к блокировке аккаунта. Кулдаун не делает её разрешённой. Используйте только свой аккаунт и канал, где публикации разрешены. Не передавайте токен другим людям.

## Установка

1. Откройте [последний релиз](https://github.com/niconexeder/TradeDesk/releases/latest).
2. Скачайте `TradeDeskBootstrap.exe` и запустите его.
3. Бутстрапер установит приложение в `%LOCALAPPDATA%\TradeDesk`, создаст ярлык `TradeDesk` на рабочем столе и запустит приложение.

Права администратора не нужны. Установка выполняется только для текущего пользователя Windows.

Бутстрапер — это установщик, лаунчер, автообновление и деинсталлятор в одном файле. При каждом запуске с ярлыка он проверяет `latest.json` на GitHub:

- если версия новее, скачивает `TradeDesk-win-x64.zip`, проверяет SHA-256 и атомарно заменяет папку `app`;
- настройки в `data\` и профиль WebView2 сохраняются;
- если сети нет, но приложение уже установлено, запускается установленная версия.

Требуется Windows 10/11 x64 и Microsoft Edge WebView2 Runtime. Если WebView2 не установлен, приложение предложит открыть страницу загрузки.

Сборка не подписана, поэтому Windows SmartScreen может предупредить. Если файл получен из официального релиза на GitHub, нажмите «Подробнее» → «Выполнить в любом случае».

## Обновление и удаление

Обновление происходит автоматически при запуске ярлыка. Закройте TradeDesk перед установкой обновления, если оно уже было скачано; если приложение запущено, бутстрапер сначала активирует его.

Удаление:

- «Параметры» → «Приложения» → «Установленные приложения» → TradeDesk → «Удалить»;
- или запустите `%LOCALAPPDATA%\TradeDesk\TradeDeskBootstrap.exe --uninstall`.

Удаляются приложение, ярлык, запись в списке программ, настройки, профиль WebView2 и зашифрованные токены. Вернуть их после удаления нельзя.

## Токены и данные

- Токены Discord сохраняются зашифрованными в `%LOCALAPPDATA%\TradeDesk\data\tokens.dat` с помощью Windows DPAPI в режиме `CurrentUser`.
- Они не записываются в localStorage, журнал или обычные текстовые файлы. Расшифровать файл может только этот пользователь Windows на этом компьютере.
- После перезапуска приложения токены автоматически подставляются в карточки с теми же ID.
- При удалении карточки её сохранённый токен удаляется. При редактировании поля старый токен сразу удаляется из хранилища; новый сохраняется после успешной проверки.
- Один и тот же токен нельзя подключить в двух карточках. Сравнение идёт по точному значению после отбрасывания пробелов по краям.
- DPAPI не защищает от вредоносной программы, запущенной под той же учётной записью Windows. Не запускайте неизвестные файлы и не передавайте токен третьим лицам.
- Настройки карточек хранятся в профиле WebView2: `%LOCALAPPDATA%\TradeDesk\WebView2`.

## Поведение приложения

- Интерфейс работает только с локальным сервером на `127.0.0.1:47831`; внешние переходы, новые окна и запросы разрешений WebView2 заблокированы.
- Приложение одноэкземплярное: повторный запуск активирует уже открытое окно. Закрытие окна останавливает локальный сервер.
- До 20 карточек; у каждой независимые таймер, счётчик и журнал. Каналы обходятся по кругу: одна отправка за интервал.
- 429: ожидание не меньше `retry_after` и заданного кулдауна. 400/401/403/404/5xx: остановка. При сетевой ошибке автоматического повтора нет, чтобы не дублировать публикацию.
- Массовые упоминания отключены через `allowed_mentions`. Тела запросов, ответы Discord и секреты не логируются.

## Сборка из исходников

Нужны Node.js 22+, .NET SDK 8+ и .NET Framework 4.8 `csc.exe` (входит в Windows 10/11).

```cmd
node scripts/build-release.mjs 1.0.0
```

Скрипт собирает приложение, компилирует бутстрапер, создаёт ZIP, `latest.json` и заметки релиза в `dist\`. Для загрузки на GitHub нужны только:

- `dist\TradeDeskBootstrap.exe`
- `dist\TradeDesk-win-x64.zip`
- `dist\latest.json`

ZIP — это payload для бутстрапера, а не отдельный установщик. Не загружайте отдельные DLL или старый `TradeDeskSetup.exe`.

Тесты:

```cmd
node --test tests/*.test.mjs
```

Структура: `desktop/` — C# WinForms-хост и WebView2; `installer/` — бутстрапер и DPAPI-хелпер; `public/` — интерфейс; `accounts.mjs`, `campaign.mjs`, `server.mjs` — локальный сервер и сеансы; `tests/` — регрессионные тесты.

Реальная авторизация и публикация требуют вашего аккаунта и разрешённого канала и не подтверждаются тестами с подменённым транспортом. Никому не присылайте токен для проверки.
